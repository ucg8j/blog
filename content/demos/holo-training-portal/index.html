Complete the Interface Basics module

This local demo is designed for browser agents. It has a launch step, gated navigation, a simulated media wait, quiz feedback, and an explicit completion screen.

The task is simple: launch the module, complete each slide, answer the quiz correctly, and finish the course.

Module details

Estimated duration: two minutes. Completion requires five checklist interactions, one timed media step, and one quiz question.

1. Learn

Read the rule and acknowledge the important point.

2. Watch

Wait for the simulated media progress to finish.

3. Check

Answer a quiz and use feedback if the first attempt is wrong.

4. Confirm

Confirm completion before the final success screen appears.
